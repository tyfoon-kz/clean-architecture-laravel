# Framework as detail

Laravel остается полезным инструментом проекта: он принимает HTTP, поднимает container, запускает console commands, работает с очередями, миграциями, events и Filament. Но бизнесовый процесс не должен исчезать внутри framework API.

Если завтра вход изменится с Filament на API или импорт файла, смысл сценария остается прежним. Меняется adapter. Поэтому framework является внешней деталью вокруг процесса, а не самим процессом.
