# Architecture check workflow

make architecture-check становится коротким входом для архитектурных проверок. Он не заменяет мышление, но быстро показывает, что базовые границы не сломаны.

```bash
make architecture-check
make check
```

Если Deptrac падает, сначала читай направление зависимости. Не нужно сразу добавлять исключение. Исключение допустимо только как явно описанный компромисс.
