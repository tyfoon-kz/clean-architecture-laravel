# Change impact

Если меняется форма Filament, удар должен остаться в Presentation.

Если меняется storage, удар должен остаться в Infrastructure.

Если меняется правило номенклатуры, изменение должно попасть в Domain и затронуть все actor-specific сценарии явно.

Clean Architecture не обещает меньше файлов. Она обещает более понятную цену изменения.
