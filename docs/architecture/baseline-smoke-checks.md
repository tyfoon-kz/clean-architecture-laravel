# Baseline smoke checks

Перед архитектурным рефакторингом проект должен иметь понятную рабочую точку. Этот файл фиксирует минимальный baseline: команда запускается из корня проекта, Makefile виден, Composer читает правильный composer.json, Laravel может загрузить приложение, а тестовый запуск показывает текущее состояние проекта.

Минимальный набор проверок:

```bash
pwd
make help
composer dump-autoload
php artisan about
make check
```

Если одна из проверок падает, сначала нужно описать слой падения: рабочая машина, зависимости проекта, Composer autoload, Laravel bootstrap, база данных, frontend build или тесты. Clean Architecture не начинается с новых папок. Она начинается с понимания, что проект работал до изменения.
