# Nomenclature actors

Один похожий результат может приходить от разных business actors.

- Администратор создает номенклатуру вручную через Filament.
- Внешняя система отправляет номенклатуру через API.
- Оператор загружает документ импорта.

Процесс похожий, но причина изменения разная. У каждого входа могут быть свои правила валидации, сообщения об ошибках, audit trail и требования к идемпотентности. Поэтому курс не прячет все за одним большим методом createProduct().
